# Pokebar releases

Download [Pokebar 2.5.90](https://github.com/actioneerhimi/poketokenbar-releases/releases/tag/v2.5.90).

A redesigned Home puts what you check most on one screen: a compact companion card, official limits for every provider you use with a strip to jump between them, and today's usage with a 7-day trend and per-provider totals. Type, ability and attack points move to a Pokémon details page.

Battle planning fits on one screen, and choosing an action whose budget is full now swaps it with the nearest turn that uses it. Settings are easier to scan, with clearer switches.

If Claude Code is signed out, Home now says so and explains how to sign in again. Pokémon names show correctly before evolution data finishes loading.

Supports Apple Silicon and Intel on macOS 14 or later. The app and installer are signed and notarized, and updates use the existing signed feed.
