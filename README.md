# Pokebar releases

Download [Pokebar 2.5.77](https://github.com/actioneerhimi/poketokenbar-releases/releases/tag/v2.5.77).

Live Battles beta shows online players. Enable it in **Settings → App → Beta**, open **Start Live Battle → Players**, then choose **Challenge** beside an available player. They can accept or decline the request. Requests also appear on Home. Both players need **2.5.77** for presence and invitations.

**Find a player** still offers random matchmaking. Each player chooses a move before the turn plays. Trainer practice remains available.

The battle log is removed. Victory finishes its animation, returns to Home, and clears the completed fight for the next battle. Saved Pokémon and trainer gym progress stay intact.

The app supports Apple Silicon and Intel Macs running macOS 14 or later. The app and installer are Developer ID signed and notarized. All users receive the update through the existing signed update feed; Live Battles remains optional.
