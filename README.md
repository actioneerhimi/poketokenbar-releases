# Pokebar releases

Download [Pokebar 2.5.76](https://github.com/actioneerhimi/poketokenbar-releases/releases/tag/v2.5.76).

Live Battles beta now includes player matchmaking. Enable it in **Settings → App → Beta**, open **Start Live Battle**, then choose **Players → Find a player**. Each player chooses their own move; turns play when both choices are ready. Trainer practice remains available.

The battle log is removed. Victory finishes its animation, returns to Home, and clears the completed fight for the next battle. Saved Pokémon and trainer gym progress stay intact.

The app supports Apple Silicon and Intel Macs running macOS 14 or later. The app and installer are Developer ID signed and notarized. All users receive the update through the existing signed update feed; Live Battles remains optional.
