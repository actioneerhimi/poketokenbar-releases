# PokeTokenBar releases

This is the release channel for the custom PokeTokenBar build maintained by
[actioneerhimi](https://github.com/actioneerhimi), based on
[chattymin/PokeTokenBar](https://github.com/chattymin/PokeTokenBar).

[Download PokeTokenBar 2.5.4](https://github.com/actioneerhimi/poketokenbar-releases/releases/download/v2.5.4/PokeTokenBar-2.5.4.zip)
or read [the release notes](https://github.com/actioneerhimi/poketokenbar-releases/releases/tag/v2.5.4).
This release is signed with Developer ID and notarized by Apple. It fixes
menu-bar panel positioning and leaderboard profiles and battle challenges.

Requires macOS 14 or later. Release packages support Apple silicon and Intel Macs.

## Updating older custom builds

Custom builds through 2.5.3 do not have this update channel configured. They need
one manual installation of a release from this channel. Quit PokeTokenBar,
extract the downloaded ZIP, and replace PokeTokenBar in Applications. Existing
Pokémon progress and account data remain in Application Support.

After this first installation, use Settings → Updates → Check for Updates for
future releases. Both players need an active battle strategy before starting
a leaderboard challenge.

This repository contains release information and app downloads. It is separate
from the original author's distribution channel and the private leaderboard server.
